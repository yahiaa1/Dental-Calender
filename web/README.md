# Dental Calendar Web Portal 🦷💻

بوابة الويب المتكاملة لإدارة وحجز مواعيد عيادة الأسنان على أجهزة الكمبيوتر واللابتوب.

## المميزات الرئيسية:
1. **مزامنة فورية حقيقية (Real-Time Bidirectional Sync)**:
   - متصلة مباشرة بنفس قاعدة بيانات Firebase Cloud Firestore (`dental-calender-ef240`).
   - أي حجز أو تعديل أو إلغاء يتم على اللابتوب يظهر فوراً في نفس اللحظة على هواتف الأندرويد والتمريض، والعكس صحيح بدون أي تأخير أو حاجة لإعادة تحميل الصفحة.

2. **جدول المواعيد وعرض الكراسي**:
   - عرض مواعيد كرسي 1 وكرسي 2 جنباً إلى جنب بشكل زمني مرتب.
   - فلترة حسب الكرسي وحسب حالة الموعد (مؤكد، غير مؤكد، تم الحضور، ملغي، لم يحضر).
   - إحصائيات يومية فورية (إجمالي المواعيد، الإيراد المتوقع بدون المواعيد الملغاة).

3. **حجز وتعديل المواعيد**:
   - إكمال تلقائي لأسماء المرضى المسجلين مسبقاً.
   - حساب تلقائي لوقت انتهاء الموعد بناءً على نوع الإجراء وسعره.
   - تصنيف المرضى (VIP، ملتزم، عادي، كثير الإلغاء، متأخر).

4. **إجراءات واتساب السريعة (WhatsApp Web)**:
   - فتح محادثة WhatsApp مباشرة مع المريض برسائل القوالب المعتمدة (تأكيد الحجز، تذكير قبل الموعد، تذكير قبل ساعة، إلغاء، تعليمات بعد العلاج).

5. **القوالب ومواعيد العمل**:
   - تعديل نصوص قوالب الواتساب من اللابتوب وتنعكس فوراً على هواتف التمريض.
   - تعديل ساعات العمل ويوم الإجازة ومزامنتها لحظياً.

6. **سجل المرضى والتقارير**:
   - بحث فوري بالاسم ورقم الهاتف.
   - تقارير الإيرادات الشهرية والمحصلة وتوزيع الإجراءات الأكثر طلباً.

## تسجيل الدخول الافتراضي:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `1234655`
*(أو أي مستخدم مسجل في إدارة المستخدمين)*

## طريقة التشغيل:
- تشغيل ملف `start_web.bat` مباشرة بنقرة واحدة، وسيتم فتح المتصفح على:
  **http://localhost:5173/**
- يمكن فتح الرابط أيضاً من أي جهاز كمبيوتر آخر على نفس شبكة الواي فاي.
